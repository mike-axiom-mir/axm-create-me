## First useful studio trial

Pick a repeated gap already visible in specialist evidence. The owning design
repository runs the bounded experiment; shared UC machinery receives only a
demonstrably reusable mechanism with an explicit contract. Compare a simple
baseline with the candidate on unused cases.

The handoff should contain construction causes, donor revision/license,
parameters, actual observations, failures and the receiving department's next
check. Keep source assets, generated exports, rendered observations and judgment
separate. A numerical geometry PASS cannot become an Art/QA verdict.

This map proposes recipients without claiming their adoption. Existing specialist
status files retain their owners and evidence. No department is declared mature,
no generic solver is installed, and the studio dashboard remains read-only.
